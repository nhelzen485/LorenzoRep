## Features
- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status (Pending / Completed)

## About
A simple Laravel CRUD application for managing personal tasks, built using the
Routes → Controller → Model → Database → Blade flow.

## Tech Stack
- Laravel 11
- Blade templates
- Bootstrap 5 (CDN)
- SQLite

## Live Demo
This project runs in a GitHub Codespace. To try it:
1. Open this repo in a Codespace
2. Run `composer install`
3. Run `php artisan serve`
4. Open the forwarded port 8000
